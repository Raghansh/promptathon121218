## 📌 Overview

**Promptathon** is a curated repository containing prompt engineering patterns, few-shot prompting templates, reasoning structures, and generative AI experiment logs developed during hackathon challenges.

---

## 💡 Prompt Categories & Patterns

1. **Chain of Thought (CoT)**: Step-by-step reasoning prompts for complex logical and coding tasks.
2. **Role-Based Persona Prompting**: System instructions for security auditing, penetration testing guidance, and architectural reviews.
3. **Structured Output Enforcement**: JSON schema validation and deterministic output generation.
4. **Few-Shot Task Demonstrations**: Context optimization for high-accuracy completions.
